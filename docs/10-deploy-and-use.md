# 10 · 装到手机上，然后用起来

这篇**不讲代码、不讲架构**，只干一件事：跟着从头敲到尾，你手机上就有一个能日常用的
QwenPaw 遥控器。全程 30~40 分钟，其中一半是等 DevEco Studio 下组件。

想改代码、想看设计为什么长这样，去看 [05](05-architecture.md) 之后的那些篇；
这篇一律不管。

---

## 第 0 步：先确认手上有这四样

| | 为什么要 |
| --- | --- |
| 一台 **HarmonyOS NEXT（6.0.0 / API 20）及以上**的手机 | 工程只声明了 `phone` / `tablet` 两种形态 |
| 一台**日常在用 QwenPaw 桌面版**的电脑 | 模型、工具、历史全在那边，手机只是遥控器 |
| 手机和电脑在**同一个 Wi-Fi / 同一网段** | 手机走移动数据一定连不上，这不是 bug |
| 电脑上装 **DevEco Studio 6.x**（自带 API 20 SDK 和 `devecocli`） | 构建、签名、装机全靠它 |

另外要一个**华为开发者账号**，但只在第 3 步（签名）用一次。
**光是编译不需要任何账号、任何证书**——第 2 步在干净克隆上就能过。

DevEco Studio 从华为官网下（<https://cn.devecostudio.huawei.com/>，历史版本在
<https://developer.huawei.com/consumer/cn/deveco-studio/archive/>），装完用 DevEco Studio
里的 **SDK 管理器**确认 **API 20** 的 SDK 已经装上。
`devecocli` 是命令行工具，随 DevEco Studio 一并提供（没有 IDE 也可以用它的
Command Line Tools 装）。**没配它也不影响**，本文每一步都写了 DevEco Studio 里的等价点法。
**QwenPaw 桌面版不在本文的下载范围内**——它是另一件事，
本文只假设"你本机已经跑着它"。

下面所有命令都假设你已经进到工程根目录。命令行窗口里先进去一次（把路径换成你自己的）：

```bat
cd /d C:\你的路径\QwenPawMobile
```

---

## 第 1 步：把工程拿到本地

```bat
git clone https://github.com/errboy/QwenPawMobile.git
```

放在哪个目录都行，**路径里别带中文和空格**（工具链在这上面踩过坑）。

## 第 2 步：先让构建过（这一步不要账号）

```bat
devecocli check arkts
devecocli build
```

看到产物就成功了：`entry/build/default/outputs/default/` 下面有一个 `.hap`。

- 这时产出的是**未签名包**（文件名里带 `unsigned`），**装不上手机，这是预期行为**。
  日志里会有一句 `[localSigning] ... is missing; building unsigned.`，不用管它。
- 没装 `devecocli` 也完全可以：用 DevEco Studio 打开这个目录，
  菜单 Build → Build Hap(s) 干的是同一件事。后面每一步都有 Studio 里的等价点法。

## 第 3 步：签名（要华为账号，只这一步）

```bat
devecocli auth login
devecocli signature generate
```

- `auth login` 会弹浏览器让你登录华为账号——**这一步必须你本人点**，别的程序代不了。
- Studio 里的等价做法：File → Project Structure → Project → Signing Configs，
  勾上 *Automatically generate signing*。
- **签名之前先改应用标识**：打开 `AppScope/app.json5`，把 `bundleName` 改成你自己的
  （比如 `com.<你的名字>.qwenpawmobile`），顺手改一下同文件里的 `vendor`。仓库里带的那串是
  **原作者的应用标识**，而签名材料是按"你的账号 + 这个标识"申请的，不改过去装机可能被拒。
  改完 `bundleName` 再跑 `signature generate`。应用显示名在
  `AppScope/resources/base/element/string.json` 的 `app_name` 里，那是另一件事（叫什么随你，
   不影响签名）。
- 一个提醒：`signature generate` 会把真实口令**写回** `build-profile.json5`。
  如果你之后还要把工程提交回 git，先按 [02](02-build-and-sign.md) 第 3 节把口令挪回
  `external-signing-config.json` 并还原空占位。**带口令的 `build-profile.json5` 绝不能进提交。**
  那个文件该长什么样，见本文**附录 A**（照抄样例改名即可，别自己凭空编字段）。

## 第 4 步：插上手机，装

先在手机上打开开发者模式：**设置 → 关于本机 → 连点"版本号"直到提示已开启 → 开发者选项 → USB 调试**，
然后插数据线。

```bat
devecocli device list
devecocli run --device 上面查到的序列号
```

输出里有 `Smoke: PASS` 就是**装上了并且打开过**。两个必然会撞上的坎：

| 现象 | 真相 | 怎么办 |
| --- | --- | --- |
| `Error Code:10106102 ... device screen is locked` | 包**已经装上了**，只是启动被锁屏挡住 | 解锁手机，再执行一次 `devecocli run --device <序列号> --skip-build` |
| 装机失败、提示签名不一致 | 你换过一次签名证书 | `devecocli run --device <序列号> --uninstall`（会先卸旧的） |

电脑上同时连着真机和模拟器时，**所有设备类命令都必须带 `--device`**，否则 CLI 直接报"多设备"。

## 第 5 步：让手机连得上桌面端（最容易卡住的一步）

QwenPaw 桌面版**只听自己这台电脑**（`127.0.0.1`），端口还是每次启动随机换的。
所以手机直连必然连不上——这跟 App 没关系，是桌面端的绑定地址决定的。

仓库自带一个守门代理解决它，**桌面端一行都不用改**。Windows 下：

```bat
tools\qp-gate\start.bat
```

第一次跑它会问你三件事：手机端登录用的**用户名**、**口令**、以及**放行哪个网段**
（它会把你电脑当前所在网段作为默认值打出来，回车采用即可）。
接着弹一次 UAC 窗口，点"是"——那是在防火墙里放行 61700 端口。
**这条放行是永久的**：关掉网关窗口、重启电脑都还在（网关停了它也不会自己删）。
不想让局域网再连这台机器时，明确地删掉：

```bat
tools\qp-gate\start.bat firewall-remove
```

然后这个窗口会打出一行你**马上要用**的东西：

```
手机填: http://<你电脑的局域网IP>:61700
```

**这个窗口不要关**，它就是网关；最小化可以。要看当前生效的配置、或者再看一遍那行地址：

```bat
tools\qp-gate\start.bat show
```

要改口令 / 换端口 / 改网段：

```bat
tools\qp-gate\start.bat config
```

每一项都把**当前值当默认**，一路回车等于什么都没改。别用"初始化"那条命令去改配置，
那会把手机上已登录的状态全部作废（原因写在 [04](04-desktop-cooperation.md)）。

**不用的时候把它关掉**——在那个窗口里按 `Ctrl+C`（Mac/Linux 上跑的前台进程一样）。
它开的是"局域网里谁能摸到你这台电脑"的一扇门，中间只隔一个登录口令；能用不等于该一直开着。
关掉**不会**要手机重新登录，也**不会**删掉上面那条防火墙放行，所以下次 `tools\qp-gate\start.bat`
一开，手机直接就连上了。

**窗口没了不等于进程没了**——它是被脚本或后台拉起来的时候根本没有窗口。那种也用一条命令收，
有没有窗口都一样：

```bat
tools\qp-gate\start.bat stop
```

它只停这个工具自己拉起来的那个进程；要是端口上恰好坐着别的服务，它会拒绝动手、把那个进程
指给你看，然后告诉你没停——不会替你杀掉不认识的东西。想自己核一眼还在不在跑：

```bat
netstat -ano | findstr :61700
```

只有带 `LISTENING` 的那一行才是真的还在跑（行末那列就是进程号）；满屏 `TIME_WAIT` 是系统在
自己收尾，过一会儿自然没了，不用管。想让局域网连口的放行也一并消失，跑
`tools\qp-gate\start.bat firewall-remove`（要你在 UAC 里点一下）。

不是 Windows 的电脑：

```bash
python3 tools/qp-gate/qp_gate.py --init     # 首次：设账号口令
python3 tools/qp-gate/qp_gate.py           # 启动
python3 tools/qp-gate/qp_gate.py --stop    # 停（同样的认领规则，认不出是自己的就不动）
```

防火墙这一步它不代劳，你自己放行 TCP `61700`（`sudo ufw allow 61700/tcp`）。

## 第 6 步：手机上第一次登录

1. 打开 **QwenPaw Mobile**，看到的是登录页，它**不问你 IP**，而是让你扫。
2. 先点 **「登录配置」** → 把 **端口填 `61700`**（默认是 8088；不改这里就扫不到网关）
   → **「保存并返回」**。
3. 点 **「扫描局域网」**，进度会显示"已检查 x/254 · 发现 y 台"。
4. 列表里出现你那台电脑（标着 **「需登录」**）→ 点选它。
5. 在 **「登录配置」** 里填第 5 步设的用户名和口令 → 回到登录页点 **「登录」**。
6. 进到主页，顶上那行写着 `服务器: http://…:61700`，就说明连上了。

扫不到东西的排查顺序（更多见 [09](09-troubleshooting.md)）：

1. 网关窗口还活着吗？在电脑上跑 `tools\qp-gate\start.bat discover`，
   它会一次回答"上游端口是几 + 通不通"。
2. 手机和电脑真的在同一个网段吗？（Wi-Fi 名一致还不够，访客网络通常互相隔离。）
3. 第 2 步的扫描端口填了 `61700` 没有？
4. 电脑防火墙有没有真的放行 61700？重新跑一次 `tools\qp-gate\start.bat config`
   或 `start.bat firewall` 会再补一次。

## 第 7 步：日常怎么用

下面这些名字都是**屏幕上真的写着的字**，照着找就行。

### 7.1 主页

- 顶上：`服务器: …` / `用户: …`，右上角 **「退出」** 和 **「主题 ▾」**；点「主题 ▾」出
  **`跟随系统` / `浅色` / `深色`** 三条菜单，当前那条带 `✓`。
- 会话列表按来源分组：**控制台会话**、**微信机器人**、**飞书机器人**、**其他渠道**。
  默认收起，只留**主会话**（标着 `▶ 主会话`），长按别的会话可以把它设成主会话；
  想看全部点 **「显示全部会话」**。
- 会话行上会直接告诉你状态：`⏳ 进行中`、`🔒 3 项待审批`。
- **「新建会话」** 在底部；也可以在电脑端先发起，手机这边会自己同步过来。
- 最下面一行是本机存储情况：`媒体缓存 12.3 MB · 未发送草稿 2 条`，右边 **「清理」**。
  这句提示值得记住：**聊天记录保存在电脑端，这里只清理手机上的副本**——手机上没有
  可以误删历史的东西。

### 7.2 对话

聊天页底部那块输入区一共**三条横带**，从上到下：

1. **工具带**：三个小图标 —— `A`/`T` 切语音与文字、`＋` 打开附件菜单、
   `×` 清空输入框里的文字（附件各自有自己的 `×`）。输入框是空的时 `×` 是灰的，
   点它没有反应；一有字就变成**红色**（它是这一条带上唯一会扔掉你已打内容的键），
   清完回灰。
2. **选择器带**：那一排 chip（见 7.6）。
3. **输入带**：输入框和发送键，整幅宽度都给它们。

打字，**「发送」** 即可。回答是**流式**出来的，顶上会显示 `● 生成中`，
中间过程（思考块 `💭 深度思考`、工具调用 `🔧 工具名`）都会渲染。

- 回复里的 **markdown 会上屏**：加粗、斜体、删除线、行内代码、链接文字、标题、列表、引用、
  代码块，以及**表格**——表格画成等宽的网格，表头加粗，每列按电脑端写好的方式左/中/右对齐。
  写得不够规范的（比如句子里只出现一个 `|`、列数多到七列）就**照原样当文字显示**，
  不会变成一堆对不齐的框。

- 思考块**跟着这一轮走**：正在想的时候是展开的（能看见它逐字出来），这一轮的正文一开始
  它就自己收起，把屏幕让给回复；收起后右边写 `▾ 看想法`，点一下重新展开（`▴ 收起`）。
  重进老会话时思考块默认是收着的。

- 工具调用那张卡（`🔧 工具名`）默认只有一行标题，点一下才展开看它说了什么。连着来两张以上
  会并成一行 `🔧 工具卡 ×N ▾ 看详情`，点组头展开全部。**但只要那张卡刚把一份文件交到你手上**
  （电脑端"发文件"给你），它就**不折进组里**、单独占一行，卡片上面直接就是那份文件 ——
  图能点开看、视频语音能播、文档右边有 `查看 ›`，全都不必展开卡片。电脑端把字节直接嵌在消息里
  的那一份另有一种长相（`内嵌文件`，没有 `查看 ›`），见下面「文件气泡」。
  **找文件不必逐张翻**：带文档的那张卡，标题写的就是那个文件名（`📁 测试1.txt`，工具名字在它
  下面一行），交付那几行也是主色的，在一排黄色的工具卡里会自己跳出来；或者点顶栏 **`📁`** 打开
  资产面板，那份会话里交过来的文件全在一处，每行的 **`定位`** 直接把屏幕滚到那张卡上。
  （标题写文件名的目前只有**文档**那一类；图 / 视频 / 语音三张卡的标题还是工具名，但卡片上面
  就是那张图、那个播放器、那条语音，认它不用看标题。）

- 想打断：生成时发送键会变成 **「停止」**。生成中再发新消息，键会变成 **「发送并插队」**，
  并且提示 `发送将打断当前生成…`。
- 断网/切后台再回来，App 会自己重连（2/4/8 秒退避，最多三次），不用你手动刷新。
  转录里那行 `连接中断，N 秒后自动重连…` 说的是**眼下这一次等待**，连上了、或者这一轮
  其实已经结束，它就会自己消失；换成 `重连失败。后台仍在生成时会自动继续探测，稍后可看到最新内容`
  才是真没连上（去看电脑端和网关）。
- 有时一条**发不出去**：你打的那句是随"发送"这个请求本身交出去的，电脑端可以当场把它拒收
  （比如这个会话正在被电脑端用着、或请求太频繁）。这时那条气泡会**留在屏幕上**、下面标一行红字
  `未送达`，另有一句 `这条没有发到服务器，长按它可以引用重发` —— 长按它，原话回到输入框，
  改不改都由你，再发一次即可。**这一步别拖**：`未送达` 只活在当前这个会话窗口里，退出去再进来，
  电脑端没有这句话、手机上那份也一起没了（它不像草稿那样会被留下）。
- **电脑上发起的轮次，你不用退出重进也能看到**（10 秒一次的统一轮询）。
- 打了一半退出去，它会存成草稿再回来；下次进这个会话自动填回输入框，
  主页那行也会计数（`未发送草稿 n 条`）。

### 7.3 说话（不用键盘）

工具带上把 `T` 切成 **`A`**：`T` 是文字（用系统输入法，听写也归输入法管），
`A` 是语音。切到语音态后整条输入框变成 **「按住 说话」**：
**按住不动就开始录，松手就把这一段音频发出去**，录的过程中手指往上滑、文案变成
`松开取消`，此时松手就丢弃不要了。App 里没有第二个语音转文字引擎——
你说出去的就是那段音频，要不要转文字由电脑端决定。

第一次按会弹麦克风权限，给一次就不再问。**拒绝过**之后再按不会又弹一次框，
而是直接把你带到系统的权限设置页（App 里没有第二次弹窗，只有系统那一层能改）。
想撤销授权也只能在那里做：**设置 → 应用 → 本 App → 权限 → 麦克风**。

### 7.4 发东西给它（`＋` 菜单）

点工具带上的 **「＋」**，能看到：

- **`🖼 相册（图片/视频）`**、**`📄 手机文件`**、**`🎵 音频`**、**`🎙 录一段语音`**、**`📝 长文本`**
  —— 这些都走系统的选择器，所以 App 不申请任何存储权限。
- **`🧩 技能 (电脑)`** 打开一份技能列表：一行一个技能，写名字和简介，右边那个 `/技能名`
  就是点下去会得到的东西。点一下**关掉列表**、把 `/技能名` 写进输入框，发不发送你决定；
  在后面接着打一句话就是给这个技能的正文（`/技能名 你的问题`）。这里没有"在手机上开启
  技能"这回事——启用与配置都在电脑端。电脑端没有可用技能时，这一行显示
  `🧩 电脑端没有可用的技能`，是灰的、点不动。
- **`🔌 MCP (电脑)`** 打开一份**只读**清单，能展开看每个客户端暴露的工具。
  手机上**不能**开关 MCP 客户端、也**不能**改它的工具白名单——那是桌面端的全局配置。
  清单也不显示 `url`/`headers`/`env`/`args`（手机屏幕是会被拍照的）。

### 7.5 打 `/`：快捷指令

输入框开头打一个 `/`，会浮出补全列表，按类别分组（**内置 / 会话 / 控制 / 后台 / 模式 /
循环模式 / 技能 / 自定义** 等）。词表来自电脑端，所以不同版本会有差别。

### 7.6 输入框上面那一排选择器

最多三枚，从左到右：**循环模式**、**模型**、**审批**，默认都写着"跟着电脑端"
（`默认模式` / `电脑端默认` / `电脑端默认`）。**电脑端没有可选项时，对应那枚就不出现**
（只有审批一直在）——这是正常的，不是 App 少了功能。点开可以换：

- **模型**：换成这台桌面端上配好的其它模型槽位。
- **审批**：`严格模式` / `智能模式` / `自动模式` / `关闭模式`。
  手机自己**不会**替你批准任何东西，但这枚选择器决定的是**电脑端还要不要问你**：
  一旦选了 `自动模式` 或 `关闭模式`，这个会话后面的工具调用就**不再弹审批卡片**了。
  想保持"每一步都过我的手"，就留在 `电脑端默认` 或 `严格模式`（取舍详情见
  [SECURITY.md §3.7](../SECURITY.md)）。
- **循环模式**：需要多轮自动推进的任务模式。

选完记在**这个会话**上（下次进来还是它），别的会话各选各的；
想清掉这些选择，去清理页勾 `会话偏好（模型 / 审批 / loop / 发过的媒体）`。

### 7.7 引用已经说过的话

**长按任意一条气泡**，出来的菜单是 `引用这段文字` / `引用这张图片` / `引用这段视频` /
`引用这段语音` / `引用这个文件`。选完那句话/那个文件会回到输入框（引用条上标 `↩ …`），
你接着写要问的内容再发送。

文字气泡的菜单里还多一条 **`复制这段文字`**：进剪贴板的是这条消息的**原文**（markdown
源码，不是屏幕上的样子）——粘到备忘录或别的聊天里再渲染，标题、列表、表格还是原样。
复制成功屏幕上会冒一句 `已复制`。

引用的文件**一个字节都不重传**——用的是电脑端已经存着的那个路径。

**太长的那句不会被砍半。** 引用超过 600 字的长回复时，输入框里放的是一段**整段整段
收尾**的开头 + 一行说明（`（这段太长，上面只是开头；完整原文随这条消息以
quote-….txt 发出，共 N 字）`），同时托盘里多出一枚 `quote-<时间戳>.txt`。发出去后
电脑端拿到的是**完整原文**的一份文本文件，而不是半截引用——转录里那条气泡照样能认出
引的是哪一段，`📁` 面板里也找得到那份文件。不想要它就点掉托盘上那枚 chip 的 `×` ——
那行说明跟着它一起消失，不会留下一句指向不存在文件的话；中途退出会话再回来也是同理，
草稿里只留那段预览（草稿存得下文字，存不下附件）。

### 7.8 这个会话里的文件和视频（`📁`）

聊天页顶上有一个 **`📁 数字`**，点开是**本会话收发过的**图片/视频/语音/文件清单。
每行右边标着字节现在在哪：**`本机 …`**（手机上有副本）或 **`仅电脑端`**。每行四个动作：

- **定位** —— 跳回说它的那条气泡。
- **下载** —— 存到相册或你选的文件夹（系统会弹确认界面）。
- **转发** —— 交给系统分享面板（微信、邮件、网盘随你）。
- **删除副本** —— 只删手机这一份，会先问你 `删除手机上的这一份？`；
  电脑端那一份不受影响，下次点开会自动重新取。它和上面三个动作排在**同一排、从左边接着排**，
  不贴着行的右边缘 —— 右边那一列是 `打开 ›` 的落点，破坏性的那一个不该长在那儿。

**`下载` 和 `转发` 是让内容离开这台 App 的沙箱**：存进相册或你选的文件夹之后，那一份
就归系统管了，清理页删不掉它，要清就得自己去相册/文件夹里删。
显示出来的文件名是**电脑端给的那个名字**，转发前扫一眼面板上写的到底是什么
（`发票.pdf` 后面多个 `.exe` 这种事，App 拦不住，只能靠你看）（详见
[SECURITY.md §3.7](../SECURITY.md)）。

### 7.9 看图、看视频、听语音、打开文件

图片点一下全屏（再点任意处关闭）；视频和语音直接在气泡里播；你自己发出去的视频也能回放。
**语音播放失败/视频打不开时，先看 [09](09-troubleshooting.md) 第 5 节**——很多是容器解不开素材，
不是 App 坏了。已知边界：**经网关播放视频可能加载不了**（系统视频组件加不上鉴权头），
图片和语音不受影响。

手机上的视频只是**缓存**，系统随时可以把它收回去（模拟器实测几十秒就收一次，真机待验）。
收回之后气泡上的时间会停在 `00:00`、点了没反应——这不是坏了，**退出这个会话再进来**会重新
取一次字节，`📁` 面板里那一行也会跟着回到「仅电脑端」。

**文件气泡**不预览内容，只列两行：`📄 文件名`，下面一行 `MD 文件 · 本机 12.3 KB`
（字节还没取回来时写 `仅电脑端`），右边一个 `查看 ›`。点这张卡片会**先从电脑端把字节取回来**
（那一行临时变成 `正在取字节…`），然后**系统自己拦一道** ——「"QwenPaw"想要打开"某某"」，
`取消` / `允许` 两个按钮只有你能点，App 不会替你按；点`允许`之后才真正交接：装了 Markdown 阅读器
就进阅读器，`.pdf` 就进 PDF 应用。这中间 App 自己**不解析任何文件格式**，匹配是系统做的。

- 那一行的「本机 / 仅电脑端」是**气泡上次刷新时**的读数，不保证是此刻的状态：外部应用打开之后
  系统随时可能把这份缓存收回去（模拟器实测几十秒就收一次）。想知道此刻字节到底在哪，看 `📁`
  面板那一行，它是当场读的。

- 电脑端有时把文件的**字节直接嵌在消息里**交过来（不给路径）。那一份上面没有名字可用，屏幕上
  就是一行 `📄 内嵌文件` / `未知类型 · 本机 N B`，而且**右边没有 `查看 ›`** —— 字节确实到了这台
  手机，但它既没有可取回的路径，也没有一个能让系统阅读器认住的文件后缀，所以 App 只报它报得出的
  那两样：有这份东西、多少字节。这不是坏了，也**不进** `📁` 面板（面板只列取得回来的）。

- 没有应用能读它时给一句 `这台手机上没有能打开它的已装应用`，不会静悄悄没反应。
- 取回来的是 `📁` 面板同一份缓存，所以「删掉这一份」仍然归面板的**删除副本**和清理页管，
  气泡只管看不管删。
- 长按卡片还是**引用这个文件**，和点击各走各的。
- 外部应用标题栏显示的是缓存文件名（一串哈希 + 真后缀），**不是电脑端给的原名**——这是已知
  外观问题，动它会影响播放与清理的归类。要把名字也带走，走 `📁` 面板的**下载**。

### 7.10 审批：只有你能点

电脑端把某个工具调用挂起等确认时，手机上会出现一张审批卡片：

```
⛔ 要执行的动作
任务已暂停，等待你的决定        [批准执行] [拒绝]
```

**点了才会发出批准/拒绝**，App 里不存在任何自动批准、超时默认同意的路径。
卡片会显示还剩多久超时（`… · 300秒后超时`），超时与否都由电脑端决定，手机不会替你选。
主页上没处理完的会一直挂着 `🔒 n 项待审批`。

### 7.11 转屏与折叠屏

App 的横竖屏**跟随系统的旋转锁定**：系统开了锁定就不会乱转。
折叠屏/平板上正文行宽会封顶居中，不会因为屏宽就把一段话拉成一条横线；
外屏内屏、三折、阔折叠都是同一套分桶规则（细节见 [06](06-responsive-devices.md)）。

### 7.12 清理手机上的东西

主页那行 **「清理」** 进独立页面，六类**分开报数**、按类勾选：

`看过的视频` / `听过的音频` / `打开过的文档` / `录的音（发出去也留着）` / `其他缓存` /
`会话偏好（模型 / 审批 / loop / 发过的媒体）`。

**「清理所选 · n 项」** 之后还会二次确认（**「确认清理」**）才真的删。
不想整类清的时候，点类别右边的 **「▾ 逐条」** 把这一类摊开成一份一份，副本会缩进挂在
这一行左缘的竖线下 —— 和类别那张卡明显是两层。每份上面一行是
**文件名**，下面一行才是 `大小 · 最近写入时间`。名字有两种来源：这次启动以来打开过的会话
能现算出**真名**（如 `clip.mp4`）；还没打开过的会话显示它在设备上**本来有的那个名字**
（缓存副本 `<哈希>.<后缀>`、录音 `voice-<时间戳>.m4a`），后缀一定在，所以每份都说得出
自己是什么格式；名字太长时**中间用 `…` 省略**、尾巴上的后缀留着。重启后想认回原名，
先把对应会话打开一次。
**点名字那一行就是先看再删**：视频在页面里出画面、音频就地播、文本类文档直接在页面里
读（太大只显示开头并注明 `只显示开头 32.0 KB`；二进制或系统接不住的后缀交给系统
打开器）。勾其中几份即可，此时类别自己的勾选框会灭掉，确认文案会写成
「听过的音频（只删其中 1 个）」这种。
勾选框和逐条走的是同一次删除，没有两套规矩。
删完那行**报的是真删掉的个数**：如果系统在中间自己回收过，它会说「已清理 0 项」而不是
照着刚才按钮上的数字报。
删的全是手机上的副本；聊天记录、你发出去的东西、电脑端的一切都不受影响的在电脑端那边。
没发送成功的草稿不在这里清（怕你误丢内容），它们在输入框里等你回来。

## 这个 App 不做什么（知道边界少踩坑）

- **不做独立 agent**：模型、工具执行、历史都在电脑端。电脑关了，手机就只能看个空壳。
- **不写桌面端的全局配置**：运行配置、MCP 开关、技能启用、上传上限——手机上**只读**。
- **不自动批准任何事**：App 里没有定时默认同意、没有"这次都同意"，批准只能你在审批卡片上点。
  测试审批功能时**必须有人在场**。但它可以把**电脑端**的档位调到 `自动模式` / `关闭模式`
  （§7.6 那枚选择器），那之后就不再弹卡片了——这一层是你能拧的，拧松了后果也归你。
- **只有 HTTP，没有 HTTPS**：令牌在局域网里是明文走的，暴露面和桌面端自己的
  `/api/console/*` 一样。别把它架到公网或不可信网络里（完整取舍见 [SECURITY.md](../SECURITY.md)）。
- **不上应用市场**：现在只能自己构建自己装，所以每台新手机都要重走第 3、4 步。

## 附录 A · 全文提到的字段与文件在哪

### A.1 `external-signing-config.json`（签名材料，**不进仓库**）

`hvigorfile.ts` 在构建前把这份文件整体折进 build profile。它被 `.gitignore` 排除，
因为里面是 keystore 绝对路径和两个口令。仓库里放了形状样例
`external-signing-config.example.json`：**照抄成 `external-signing-config.json` 再把空值换成真话**。
注意读它用的是 `JSON.parse`，所以必须是**严格 JSON**（不许注释、不许尾逗号、值里不许写单引号）。

```json
{ "signingConfigs": [ { "name": "default", "type": "HarmonyOS",
    "material": { "certpath": "…", "keyAlias": "…", "keyPassword": "…",
                  "profile": "…", "signAlg": "SHA256withECDSA",
                  "storeFile": "…", "storePassword": "…" } } ] }
```

**别手写这七个值。** 正确顺序：跑一次 `devecocli signature generate`（它把真值写进
`build-profile.json5`）→ 把那段 `signingConfigs` **整块复制**成这个文件 → 把
`build-profile.json5` 还原成空占位。原因：DevEco 生成的口令是用**只存在于本机的密钥**
加密的，凭空编一个值既不对也没意义。

### A.2 `gate.json`（守门代理的配置，**不进仓库**）

第一次跑 `tools\qp-gate\start.bat` 时自动生成在 `tools\qp-gate\` 里，里面有手机端登录用的
用户名和**口令的散列**（不是明文），还有令牌密钥。日常不用手改它——改口令、换端口、
改放行网段都走 `start.bat config`。字段含义逐条打印：`start.bat show`。

### A.3 `AppScope/app.json5` 的两个值

| 字段 | 作用 | 换人用要不要改 |
| --- | --- | --- |
| `bundleName` | 应用唯一标识，签名 profile 按它申请 | **要**（见第 3 步） |
| `vendor` | 厂商标识，装机后在系统里能看到 | 建议改 |
| `label` → `$string:app_name` | 手机上显示的 App 名字，值在 `AppScope/resources/base/element/string.json` | 随你，不影响签名 |

### A.4 端口对照

| 端口 | 谁在听 | 谁需要知道 |
| --- | --- | --- |
| `61700` | qp-gate（`0.0.0.0`，局域网可达） | **手机里填的就是它**；扫描端口也要填它 |
| 桌面端的随机端口 | QwenPaw 后端（只 `127.0.0.1`） | 你不用知道：qp-gate 自动发现（`upstream_port` 保持 `0`） |
| `8088` | App 里扫描端口的**默认值** | 用 qp-gate 时必须改成 61700，否则"扫描没结果" |
